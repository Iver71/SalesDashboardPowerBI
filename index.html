Global Sales Analytics Dashboard & Financial Simulation

Executive and interactive Power BI dashboard developed to centralize, internationalize and project profitability from global commercial operations.

View GitHub Repository Live Dashboard

The Challenge

Global commercial operations generated millions of rows distributed across multiple Excel files. Executives lacked a centralized reporting solution, causing delays in monthly reporting, manual processes and low visibility into profitability by region, product and sales channel.

The Solution

  • Centralized Excel data using Power Query.
  • Star schema data modeling with DAX metrics.
  • Dark Mode premium interface with intuitive navigation.
  • Financial simulation using What-If Analysis.
